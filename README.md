# Sigma Mix · виджеты

Второй Telegram-бот Sigma Mix: те же миксы, что у первого бота (`AlexQBF/mix-bot`), но ответ приходит **карточкой-виджетом**:
три вкладки, чаша с долями, состав с линейками и пачками, кнопка «Заказать», оценка 👍 / 👎.

## Как устроено

- **Подбор — от первого бота без изменений:** разбор запроса, отбор из наличия, сборка трёх миксов, проверки кода (база от 50%, один вкус один раз, названный табак, мат).
- **Таблица, правила и «мозги» — общие.** Справочник вкусов, наличие и копию Google Таблицы обновляет первый бот; этот бот только читает их из его хранилища (привязка `SHARED` в `wrangler.toml`). Поменяли инструкцию, ограничения или `text_ai` в таблице — меняется в обоих ботах. Расписания у этого бота нет.
- **Своё хранилище (`KV`):** диалоги, карточки (30 дней), оценки (год).
- **Ответ:** сразу виджет «Собираю миксы…», через 20–40 с в него ложатся три микса (правка беззвучная), подпись под карточкой — названия и доли. Под карточкой кнопки «Ещё варианты» и «Новый запрос».
- **«Заказать»:** одно нажатие сразу открывает чат с менеджером (`order_contact` из таблицы) с составом в тексте; отметка «Нажал „Заказать“» уходит в журнал фоном. Строки журнала от этого бота помечены 🧩.
- **Оценки 👍 / 👎:** копятся для «золотого фонда», смотреть — `/ratings` (только админам).
- Если Telegram не принял виджет — бот отвечает текстом, как первый, и пишет админам.

## Файлы

- `src/worker.js` — бот (код первого бота + карточка, запросы виджета, общие данные).
- `src/widget-state.js` — упаковка миксов в состояние виджета (два поля по 1 024 байта).
- `widget/mix-card.src.html` — исходник виджета; `widget/mix-card.html` — собранный, его берёт Cloudflare.
- `tools/` — сборка и проверка виджета: `cd tools && npm i && node build.mjs` (размер после сжатия должен быть ≤ 4 096 байт), `node preview.mjs` — скриншоты 320 px в светлой и тёмной теме.

## Запуск

1. Cloudflare → Workers & Pages → `mix-bot-widgets` → Settings → Variables and Secrets, тип **Secret**:
   - `BOT_TOKEN` — токен нового бота от @BotFather;
   - `WEBHOOK_SECRET` — любая случайная строка из латиницы и цифр;
   - `IMAGE_API_KEY` — ключ OpenAI, тот же, что у первого бота;
   - `SHEET_SECRET` — тот же, что у первого бота (журнал);
   - `LLM_API_KEY` — ключ Anthropic, только если в таблице `text_ai` = claude.
2. Открыть в браузере `https://mix-bot-widgets.khoroshilov-aleksey.workers.dev/setup?key=<WEBHOOK_SECRET>` — бот подключится к Telegram (с обновлениями `widget_query`).
3. Написать боту.

Команды админов: `/config`, `/find <слова>`, `/ratings`; всем — `/id`. `/reload` и `/stock` — в первом боте.

## Ограничения виджетов (Bot API, ноябрь 2026)

Одно нажатие — один вызов (`request`, `openTelegramLink`…); ссылка — до 256 символов; HTML до 4 096 байт после zlib 9; состояние до 1 024 байт; ответ на запрос — до 15 с. В рабочем Telegram виджеты работают только в личном чате с ботом. Подробно — документ проекта «widget-bot-brief».
